A make.fun entry for "Worst AI Advice: The 48-Hour Tight Line Open" — a tiny deterministic program that writes one line of the worst possible advice an AI could give, in 140 characters or fewer.

## Run it

```sh
python3 main.py
```

This writes the advice line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
